# Anleitung  

## Neues Repo erstellen
1. Auf GitHub einloggen
2. Grüner "New" Knopf drücken.
3. Repo bennen und Einstellungen vornehmen
4. Grüner "Create repository" drücken.
5. Neues File "git_basic.md" erstellen.

## Repo Lokal klonen
1. VSC öffnen
2. Mit dem Befehl "git clone [url]" das Repo klonen

## Commit erstellen
1. Mit dem Befehl "git add -A" die Änderungen für den Commit hinzufügen
2. Mit dem Befehl "git commit -m "[Mitteilung]" den Commit erstellen

## Gitignore file erstellen
1. Im Repo das File ".gitignore" erstellen.
